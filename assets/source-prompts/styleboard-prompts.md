# Styleboard Prompts

All three prompts must produce the same composition so the user can compare style only.

## Gentle Pixel

Create a cozy 2D top-down game styleboard for a small Chang'an cultural relic restoration shop. Same composition: one shop corner, a restoration workbench, a display case, one shopkeeper character, three small artifacts (terracotta fragment, roof tile, bronze mirror), and one paper-like UI panel. Gentle pixel-art inspired, warm lantern light, clay red and aged paper palette, clear silhouettes, clean game sprite readability, no text, no logos.

## Hand-Painted Guanzhong

Create a cozy 2D top-down game styleboard for a small Chang'an cultural relic restoration shop. Same composition: one shop corner, a restoration workbench, a display case, one shopkeeper character, three small artifacts (terracotta fragment, roof tile, bronze mirror), and one paper-like UI panel. Hand-painted Guanzhong folk atmosphere, warm wood, ink, aged paper, soft brush texture, elegant but readable game asset style, no text, no logos.

## Hand-Painted Guanzhong Open Map

Create a cozy 2D top-down open-map game styleboard for a Chang'an cultural relic restoration district. The player can freely walk around a small map. Include a restoration bureau building, a stele rubbing courtyard, a night-market commission stall, a relic sorting yard, winding stone paths, one shopkeeper character at player scale, six small artifact pickup points, and a fixed paper-like UI detail panel. Hand-painted Guanzhong folk atmosphere, warm wood, clay red, aged paper, ink accents, readable game-map silhouettes, no text, no logos.

## Pixel Ink

Create a cozy 2D top-down game styleboard for a small Chang'an cultural relic restoration shop. Same composition: one shop corner, a restoration workbench, a display case, one shopkeeper character, three small artifacts (terracotta fragment, roof tile, bronze mirror), and one paper-like UI panel. Pixel silhouettes with Chinese ink-wash shading, restrained palette, red seal accents, museum label UI feel, readable 2D game sprites, no text, no logos.

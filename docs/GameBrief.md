# Game Brief: 《长安修物局》

## One-Line Pitch

玩家经营一间长安城边的文物修复小铺，接收陶俑残片、瓦当、铜镜、碑拓、唐三彩碎片与旧木简；通过清理、拼合、鉴定、陈列，把沉睡的地方风物重新带回人们的日常记忆。

## Player Fantasy

玩家不是盗宝者，而是温柔、细致的修物人。每件器物都不是战利品，而是一段被泥土、时间和误读遮住的故事。玩家通过手艺、判断和审美，让旧物重新有位置。

## Core Loop

1. 接收委托或采样线索。
2. 在修复台清理、拼合、补色或拓印。
3. 鉴定年代、用途和文化标签。
4. 把修复后的物件陈列进展柜或货架。
5. 获得经费、声望和新委托。
6. 升级铺子、解锁更复杂的风物修复。

## First Playable Focus

第一版只验证开放 2D 地图上的美术投放和 UI 插槽，不做完整经济系统。参考 Plant Tales 的空间感：玩家不是被固定在一个室内场景里，而是在一张可自由跑动的小地图中移动，店铺、采样点、修复台、展柜和文化地点分布在地图上。

- 玩家可以在长安坊市小地图里自由移动。
- 6 个文物物件可以被选中。
- UI 面板显示名称、年代感标签和修复状态。
- 点击修复后，物件从残缺态切换为完整态。
- 点击陈列后，物件进入展柜 slot。

## First Proof Map

- 中央：长安修物局，包含修复台和展柜。
- 左侧：碑林/拓印院，放置残碑拓片采样点。
- 右侧：瓦当与旧构件堆场，放置莲纹瓦当和陶俑残片。
- 下方：夜市/委托摊，未来用于接委托和售卖。
- 上方：小型遗址整理区，未来用于采样和解锁新物件。
- 地图尺度：约 24 x 14 Unity units，摄像机跟随玩家。

## Visual Direction

先并行准备三套同构风格板，用户看图后选择最终量产风格：

- Gentle Pixel: 温柔像素，最稳，接近 cozy management game。
- Hand-Painted Guanzhong: 手绘国风，文化感更强。
- Pixel Ink: 像素+水墨，辨识度最高，风险最高。

## Out Of Scope For Proof

- 完整经营数值。
- 多场景探索。
- 角色动画。
- 存档。
- 批量最终美术资产。
